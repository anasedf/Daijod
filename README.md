# ได้จด (Daijod)

แอปจดรายรับรายจ่ายแบบง่าย สำหรับใช้คนเดียว ติดตั้งบนมือถือเป็น PWA ได้

- จดรายรับ รายจ่าย และโอนเงินระหว่างกระเป๋า (เงินสด, ธนาคาร, e-Wallet ฯลฯ)
- ดูยอดคงเหลือแต่ละกระเป๋าและยอดรวม
- สรุปวันนี้ / เดือนนี้ / ช่วงที่กำหนดเอง พร้อมรายจ่ายตามหมวด
- ค้นหาและกรองรายการ เลือกหลายรายการเพื่อลบทีเดียวได้
- **ปุ่มจดเร็ว**: รายการที่จดบ่อย (เช่น กาแฟ 65) แตะเดียวบันทึกเป็นของวันนี้
- **งบประมาณรายเดือนต่อหมวด**: ใช้ไปกี่ % เหลือเท่าไหร่ และเหลือใช้ได้วันละเท่าไหร่
- **รายการประจำ** (ค่าห้อง ค่าเน็ต เงินเดือน): ตั้งครั้งเดียว ถึงวันกำหนดหน้าภาพรวมถามให้บันทึกหรือข้าม
- **เทียบเดือนต่อเดือน**: กราฟรับ/จ่าย 6 เดือน และหมวดที่เพิ่ม/ลดมากสุด
- **เงินยืม/คืน**: หมวดให้ยืม / ได้รับคืน / ยืมมา / จ่ายคืน ไม่นับเป็นรายรับรายจ่าย ใส่ชื่อคนในรายละเอียด แล้วเห็นว่าใครติดใครเท่าไหร่
- นำเข้ารายการจากไฟล์ statement (กสิกรไทย, TrueMoney) พร้อมเดาหมวด กันรายการซ้ำ และจับคู่การโอนระหว่างบัญชีของตัวเองไม่ให้บันทึกซ้ำสองฝั่ง ตั้งกฎจัดหมวดเองได้
- หมวดหมู่เลือกไอคอน (140 แบบ ลายเส้นมือวาด) และสีได้ หรือใช้อีโมจิ
- เตือนให้สำรองข้อมูลเมื่อไม่เคยสำรองหรือสำรองนานเกิน 14 วัน
- ใช้งานได้แม้ไม่มีอินเทอร์เน็ต รองรับโหมดมืดตามเครื่อง

## ข้อมูลเก็บที่ไหน / ความเป็นส่วนตัว

ข้อมูลทั้งหมดเก็บใน **IndexedDB ของเบราว์เซอร์บนเครื่องที่ใช้** ไม่มีเซิร์ฟเวอร์ ไม่มี login ไม่มีค่าใช้จ่าย

แอปนี้**ไม่ส่งข้อมูลออกจากเครื่องเลย**: ไม่มีการเรียก API ภายนอก ไม่มี analytics ไม่มี cookie ไฟล์ statement ที่นำเข้าถูกอ่านด้วย pdf.js
ในเบราว์เซอร์ทั้งหมด และไม่ถูกเก็บไว้ (เก็บเฉพาะรายการที่ตรวจแล้วกดนำเข้า) โค้ดเป็นโอเพนซอร์ส (MIT) ตรวจสอบได้ทั้งหมด

ข้อควรรู้:
- ข้อมูลในมือถือกับคอมพิวเตอร์**แยกกัน** ไม่ซิงก์กัน
- ถ้าล้างข้อมูลเบราว์เซอร์ ถอนแอป หรือเปลี่ยนเครื่อง ข้อมูลจะหาย
- **กด “ดาวน์โหลดไฟล์สำรอง” ในหน้าตั้งค่าเป็นระยะ** แล้วเก็บไฟล์ไว้ที่อื่น (เช่น Google Drive) ใช้ปุ่ม “นำเข้า” เพื่อกู้คืนหรือย้ายเครื่อง

## นำเข้าจาก statement

ขอไฟล์ statement (PDF) จากแอป K PLUS หรือ TrueMoney Wallet แล้วไปที่หน้า **รายการ → นำเข้า statement** หรือหน้า **ตั้งค่า** แอปจะรู้เองว่าเป็นไฟล์ของธนาคารไหน และเลือกกระเป๋าที่ชื่อตรงกันให้

- ไฟล์ถูกอ่านในเบราว์เซอร์ทั้งหมดด้วย pdf.js ไม่ถูกส่งไปที่ไหน ถ้าไฟล์ติดรหัสผ่านให้ใส่ในแอปได้เลย (ไม่ถูกบันทึก)
- ตัวอ่านเช็คความถูกต้องกับสรุปในหัวกระดาษ (จำนวนรายการ ยอดรวม) และดูทิศทางเงินเข้า/ออกจากยอดคงเหลือที่เปลี่ยนไป
- ก่อนบันทึกจะเห็นทุกรายการพร้อมหมวดที่เดาให้ แก้ได้ทีละรายการ รายการที่ตรงกับชื่อกระเป๋าอื่น (เช่น เติม TrueMoney) จะถูกเสนอเป็นการโอน
- รายการที่เคยนำเข้าแล้วจะถูกกันไว้อัตโนมัติ (จำด้วย `importKey`) และรายการที่จดมือไว้แล้วในวันเดียวกัน ยอดเท่ากัน จะถูกเตือนว่าอาจซ้ำ
- **การโอนระหว่างบัญชีของตัวเอง** (เช่น เติม TrueMoney จากกสิกร) ถ้านำเข้าฝั่งหนึ่งเป็น “โอน” ไปแล้ว ตอนนำเข้าอีกฝั่ง แอปจะจับคู่ให้ (ยอดเท่ากัน วันที่ห่างไม่เกิน 2 วัน) และไม่บันทึกซ้ำ ไม่ว่าจะนำเข้าฝั่งไหนก่อน
- หมวดที่เลือกจะถูกจำไว้ตามชื่อคู่ค้า ครั้งต่อไปเดาถูกมากขึ้น ดู/ลบกฎที่จำไว้ และตั้งกฎเองแบบ “มีคำว่า … → หมวด …” ได้ที่ **ตั้งค่า → กฎจัดหมวด**
- ลำดับการเดา: กฎที่จำไว้ → กฎคำของคุณ → ชื่อตรงกับกระเป๋าอื่น (เสนอเป็นโอน) → ฝากเงินสด → กฎคำในตัว (`classify.ts`)
- ถ้ายอดในแอป ณ วันสิ้นสุด statement ไม่ตรงกับยอดยกไป จะมีตัวเลือกปรับยอดตั้งต้นของกระเป๋าให้ตรง

รองรับธนาคารอื่นได้โดยเพิ่มตัวอ่านใน `src/lib/statement/` (ดู `kbank.ts` / `truemoney.ts` เป็นตัวอย่าง รับข้อความพร้อมพิกัดจาก pdf.js แล้วคืนรายการ) แล้วลงทะเบียนใน `index.ts`

## ติดตั้งและรันบนเครื่อง

ต้องมี [Node.js](https://nodejs.org) 20 ขึ้นไป และ Git

```bash
git clone https://github.com/anasedf/Daijod.git
cd Daijod
npm install      # ติดตั้งครั้งแรก
npm run dev      # เปิดแอปที่ http://localhost:5173
```

คำสั่งอื่น:

```bash
npm test          # รันเทสต์การคำนวณยอดและฐานข้อมูล
npm run typecheck # ตรวจชนิดข้อมูล TypeScript
npm run build     # สร้างไฟล์สำหรับนำขึ้นเว็บ (โฟลเดอร์ dist/)
npm run preview   # เปิดดูผล build ที่ http://localhost:4173 (ทดสอบ PWA/ออฟไลน์)
```

ลองบนมือถือระหว่างพัฒนา: `npm run dev -- --host` แล้วเปิด `http://<IP ของคอม>:5173` จากมือถือที่ต่อ Wi‑Fi เดียวกัน
(ติดตั้งเป็นแอปแบบนี้ไม่ได้ เพราะ PWA ต้องใช้ https)

## ใช้บนมือถือ (ฟรี ผ่าน GitHub Pages)

1. merge โค้ดเข้า branch `main`
2. ใน GitHub ไปที่ **Settings → Pages → Build and deployment → Source** เลือก **GitHub Actions**
3. รอ workflow “Deploy to GitHub Pages” ทำงานเสร็จ (แท็บ Actions) แอปจะอยู่ที่ `https://anasedf.github.io/Daijod/`
4. เปิดลิงก์บนมือถือ
   - Android (Chrome): เมนู ⋮ → **ติดตั้งแอป / เพิ่มลงหน้าจอหลัก**
   - iPhone (Safari): ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

หมายเหตุ: repository ต้องเป็น public จึงจะใช้ GitHub Pages แบบฟรีได้ (โค้ดเป็นสาธารณะ แต่**ข้อมูลการเงินไม่ได้อยู่ในโค้ด** อยู่ในเครื่องคุณเท่านั้น)

## โครงสร้างโปรเจกต์

```
src/
  lib/
    types.ts        แบบข้อมูล Wallet / Transaction / Category
    money.ts        แปลงและแสดงจำนวนเงิน (เก็บเป็นสตางค์ จำนวนเต็ม)
    dates.ts        วันที่ภาษาไทย และช่วงวันที่
    ledger.ts       คำนวณยอด สรุป กรอง (ฟังก์ชันล้วน มีเทสต์)
    db.ts           ฐานข้อมูล IndexedDB (Dexie) เพิ่ม/แก้/ลบ สำรอง/นำเข้า
    statement/      อ่าน statement: pdf.ts (ดึงข้อความจาก PDF), kbank.ts / truemoney.ts (ตัวอ่าน มีเทสต์),
                    classify.ts (เดาหมวด + กฎ), match.ts (จับคู่โอนข้ามบัญชี), index.ts (เลือกตัวอ่าน)
  hooks/useData.ts  อ่านข้อมูลแบบ live ให้หน้าจอ
  components/       ฟอร์ม รายการ และส่วน UI ที่ใช้ร่วมกัน
  pages/            ภาพรวม, รายการ, กระเป๋า, ตั้งค่า
```

หลักการคำนวณ: ยอดกระเป๋า = ยอดตั้งต้น + รายรับเข้า − รายจ่ายออก + โอนเข้า − โอนออก
คำนวณใหม่จากรายการทั้งหมดทุกครั้ง จึงถูกต้องเสมอหลังแก้ไขหรือลบ การโอนและหมวดเงินยืมไม่นับเป็นรายรับ/รายจ่ายในสรุป
(แต่ยังมีผลกับยอดกระเป๋าตามจริง)

ไฟล์อื่นใน `lib/`: `quick.ts` ปุ่มจดเร็ว, `budget.ts` งบประมาณ, `trend.ts` เทียบรายเดือน, `recurring.ts` รายการประจำ, `loans.ts` เงินยืม, `backup.ts` สำรอง/เตือน
