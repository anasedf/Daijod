# ได้จด (Daijod)

แอปจดรายรับรายจ่ายแบบง่าย สำหรับใช้คนเดียว ติดตั้งบนมือถือเป็น PWA ได้

- จดรายรับ รายจ่าย และโอนเงินระหว่างกระเป๋า (เงินสด, ธนาคาร, e-Wallet ฯลฯ)
- ดูยอดคงเหลือแต่ละกระเป๋าและยอดรวม
- สรุปวันนี้ / เดือนนี้ / ช่วงที่กำหนดเอง พร้อมรายจ่ายตามหมวด
- ค้นหาและกรองรายการ
- ใช้งานได้แม้ไม่มีอินเทอร์เน็ต

## ข้อมูลเก็บที่ไหน

ข้อมูลทั้งหมดเก็บใน **IndexedDB ของเบราว์เซอร์บนเครื่องที่ใช้** ไม่มีเซิร์ฟเวอร์ ไม่มี login ไม่มีค่าใช้จ่าย

ข้อควรรู้:
- ข้อมูลในมือถือกับคอมพิวเตอร์**แยกกัน** ไม่ซิงก์กัน
- ถ้าล้างข้อมูลเบราว์เซอร์ ถอนแอป หรือเปลี่ยนเครื่อง ข้อมูลจะหาย
- **กด “ดาวน์โหลดไฟล์สำรอง” ในหน้าตั้งค่าเป็นระยะ** แล้วเก็บไฟล์ไว้ที่อื่น (เช่น Google Drive) ใช้ปุ่ม “นำเข้า” เพื่อกู้คืนหรือย้ายเครื่อง

## ติดตั้งและรันบนเครื่อง

ต้องมี [Node.js](https://nodejs.org) 20 ขึ้นไป และ Git

```bash
git clone https://github.com/anasedf/Daijod.git
cd Daijod
npm install      # ติดตั้งครั้งแรก
npm run dev      # เปิดแอปที่ http://localhost:5173
```

คำสั่งอื่น:

```bash
npm test          # รันเทสต์การคำนวณยอดและฐานข้อมูล
npm run typecheck # ตรวจชนิดข้อมูล TypeScript
npm run build     # สร้างไฟล์สำหรับนำขึ้นเว็บ (โฟลเดอร์ dist/)
npm run preview   # เปิดดูผล build ที่ http://localhost:4173 (ทดสอบ PWA/ออฟไลน์)
```

ลองบนมือถือระหว่างพัฒนา: `npm run dev -- --host` แล้วเปิด `http://<IP ของคอม>:5173` จากมือถือที่ต่อ Wi‑Fi เดียวกัน
(ติดตั้งเป็นแอปแบบนี้ไม่ได้ เพราะ PWA ต้องใช้ https)

## ใช้บนมือถือ (ฟรี ผ่าน GitHub Pages)

1. merge โค้ดเข้า branch `main`
2. ใน GitHub ไปที่ **Settings → Pages → Build and deployment → Source** เลือก **GitHub Actions**
3. รอ workflow “Deploy to GitHub Pages” ทำงานเสร็จ (แท็บ Actions) แอปจะอยู่ที่ `https://anasedf.github.io/Daijod/`
4. เปิดลิงก์บนมือถือ
   - Android (Chrome): เมนู ⋮ → **ติดตั้งแอป / เพิ่มลงหน้าจอหลัก**
   - iPhone (Safari): ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

หมายเหตุ: repository ต้องเป็น public จึงจะใช้ GitHub Pages แบบฟรีได้ (โค้ดเป็นสาธารณะ แต่**ข้อมูลการเงินไม่ได้อยู่ในโค้ด** อยู่ในเครื่องคุณเท่านั้น)

## โครงสร้างโปรเจกต์

```
src/
  lib/
    types.ts        แบบข้อมูล Wallet / Transaction / Category
    money.ts        แปลงและแสดงจำนวนเงิน (เก็บเป็นสตางค์ จำนวนเต็ม)
    dates.ts        วันที่ภาษาไทย และช่วงวันที่
    ledger.ts       คำนวณยอด สรุป กรอง (ฟังก์ชันล้วน มีเทสต์)
    db.ts           ฐานข้อมูล IndexedDB (Dexie) เพิ่ม/แก้/ลบ สำรอง/นำเข้า
  hooks/useData.ts  อ่านข้อมูลแบบ live ให้หน้าจอ
  components/       ฟอร์ม รายการ และส่วน UI ที่ใช้ร่วมกัน
  pages/            ภาพรวม, รายการ, กระเป๋า, ตั้งค่า
```

หลักการคำนวณ: ยอดกระเป๋า = ยอดตั้งต้น + รายรับเข้า − รายจ่ายออก + โอนเข้า − โอนออก
คำนวณใหม่จากรายการทั้งหมดทุกครั้ง จึงถูกต้องเสมอหลังแก้ไขหรือลบ การโอนไม่นับเป็นรายรับ/รายจ่ายในสรุป

## ยังไม่ได้ทำ (ฟีเจอร์เสริม)

- ส่งออก CSV
- ปรับยอดให้ตรงกับบัญชีจริง
- ธีมมืด
