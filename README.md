# ได้จด (Daijod)

แอปจดรายรับรายจ่ายแบบง่าย ใช้คนเดียว ข้อมูลเก็บในเบราว์เซอร์ของเครื่องคุณเอง (ไม่มีเซิร์ฟเวอร์ ไม่มี login)

## ติดตั้งและรัน

ต้องมี Node.js 20 ขึ้นไป

```bash
npm install      # ติดตั้งครั้งแรก
npm run dev      # เปิดแอปที่ http://localhost:5173
npm test         # รันเทสต์
npm run build    # สร้างไฟล์สำหรับนำขึ้นเว็บ (โฟลเดอร์ dist/)
```
